# Zenith House — Frontend

Interface web (React + Vite + TypeScript) do sistema de automação residencial. Fala apenas com o backend FastAPI — sem chamadas diretas a n8n ou banco.

Setup e visão geral completa do projeto: veja o [README na raiz do repositório](../../README.md).

## Comandos

```bash
npm install
npm run dev      # dev server
npm run build    # build de produção
npm run lint     # lint
npm run preview  # preview do build
```
